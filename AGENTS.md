Проект `serverest-api-tests` — учебный набор API-тестов для тренировочного магазина ServeRest (https://serverest.dev).

Стек: Java 25, Gradle 9.6.1, JUnit 6 (Jupiter), RestAssured 5.5.6, Jackson 2.19.2 (сериализация DTO), Hamcrest (матчеры).

Пишем тесты только на Java 25. Если потребуется написать на другой версии, запроси разрешение.
